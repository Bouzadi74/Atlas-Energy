# Licensing and attribution register

Atlas Energy is an academic, non-commercial project. Free access does not mean that source data
has no conditions. Each Bronze manifest records the licence statement and attribution applicable
at acquisition time.

- NASA POWER: credit NASA POWER and retain the request URL and parameters.
- Open-Meteo: use the free non-commercial endpoint and include Open-Meteo attribution.
- World Bank: check the licence attached to each indicator and attribute World Bank Open Data.
- OWID: attribute OWID and the original third-party source for every metric used.
- Ember: attribute Ember under its published Creative Commons terms.
- IRENA: retain the publication or dataset citation and its specific terms.
- ONEE, ANRE, and MEF: cite publisher, report title, edition/year, URL, and page for extracted facts.
- PyPSA technology-data: pin the release; distinguish the GPL-licensed processing code from the
  separate terms applying to its upstream input datasets.

This file is documentation, not legal advice. If project use changes from academic/non-commercial
to commercial or public redistribution, review every current publisher term before reuse.
